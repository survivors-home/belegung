# SURVIVORS HOME – Belegungsplan

Öffentliche Übersicht der belegten und freien Zeiten im SURVIVORS HOME (ohne Räume, Referenten oder interne Angaben).
Die Seite `index.html` wird täglich automatisch aus dem internen Programmplaner erzeugt (`tools/build.py`).
Bitte `index.html` nicht von Hand bearbeiten – Änderungen werden beim nächsten Lauf überschrieben.
